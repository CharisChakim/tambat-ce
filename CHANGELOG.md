# Changelog

Semua perubahan penting Tambat Community Edition dicatat di berkas ini.

## 1.0.0 - 2026-09-19

Rilis stabil pertama Tambat Community Edition.

- Terminal SSH dengan autentikasi password, private key, dan SSH agent.
- Pengelola host, multi-tab, dan impor konfigurasi OpenSSH.
- Browser file SFTP dengan unggah, unduh, pindah, ganti nama, dan hapus.
- Statistik server, verifikasi host key, dan penyimpanan secret di keyring OS.
- Installer desktop untuk Windows, Linux, macOS Intel, dan Apple Silicon.
